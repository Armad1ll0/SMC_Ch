# SMC ChEES

_Github repo for using investigating the use of the ChEES criterion for adapting the trajectory length of a Hamiltonian Monte Carlo proposal within a Sequential Monte Carlo Sampler._

## Getting Started

### Clone the Repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

### Add the necessary requirements 
pip install -r requirements.txt

### Run the 
python run_experiment.py
python analyse_results.py
